# Gesture Talk

### A Real-Time Sign Language to Voice Translation System

Gesture Talk is a real-time, browser-based assistive communication system designed to recognize hand gestures and convert them into voice output.

The project uses computer vision and machine learning techniques to detect hand gestures through a webcam, recognize the gesture, display the corresponding result, and generate speech output.

---

## 📌 Project Overview

Communication can be challenging for people who use sign language when interacting with people who do not understand sign language.

Gesture Talk aims to reduce this communication gap by providing a simple web-based system that can recognize predefined hand gestures in real time and convert them into audible speech.

The system uses a standard webcam and does not require specialized hardware such as data gloves or external sensors.

---

## 🎯 Objectives

The main objectives of Gesture Talk are:

- To develop a real-time hand gesture recognition system.
- To recognize predefined sign language gestures using computer vision.
- To convert recognized gestures into voice output.
- To provide a simple and interactive user interface.
- To explore the use of machine learning and computer vision for assistive communication.
- To create a system that can be expanded with additional gestures and languages.
